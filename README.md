### Análise Exploratória de Dados: Padrões de Atrasos em Voos (NYC Flights)

Este repositório contém a Análise Exploratória de Dados (EDA) desenvolvida em **Python** combinada com uma **Apresentação Executiva de Negócios**. O projeto utiliza um conjunto de dados massivo com mais de **336 mil registros** de voos que partiram de Nova York.

O  objetivo deste projeto é demonstrar a capacidade de extrair dados volumosos brutos, tratá-los via código e traduzir métricas técnicas em insights acionáveis para tomadas de decisão estratégicas.

* * *

### 💻 Estrutura do Repositório

*   **`Atrasos_Voos.ipynb`:** Jupyter Notebook contendo toda a esteira técnica de carga, higienização, tratamento de nulos e engenharia de dados.
*   **Apresentação Executiva (PPT):** Relatório de Business Intelligence focado em *Storytelling com Dados*, transformando os resultados do código em gráficos visuais e recomendações direcionadas a gerências e diretores (C-Level).

* * *

### 🛠️ Tecnologias e Ferramentas Utilizadas

*   **Python** como linguagem de programação principal.
*   **Pandas & NumPy** para engenharia de atributos, manipulação e limpeza das bases.
*   **Matplotlib & Seaborn** para análises estatísticas e gráficos de densidade.
*   **Jupyter Notebook** para o desenvolvimento e documentação do código.
*   **Microsoft PowerPoint** para a consolidação dos painéis gerenciais e relatórios executivos.
